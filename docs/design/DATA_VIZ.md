# WAY 2.1 Purposeful Data Visualization

## 1. The Decision-First Principle
Every chart or visualization in CREED OS must answer:
**"What concrete decision does this visualization help the user make?"**
If the answer is "it looks sophisticated" or "it fills whitespace," the visualization must be removed.

---

## 2. Visualization Mapping
| Chart Type | Primary Purpose | Allowed Contexts |
| :--- | :--- | :--- |
| **Horizontal Capability Bars** | Comparing student ability against age-appropriate benchmarks | Student profile, parent overview, teacher roster |
| **Longitudinal Trajectory Line** | Demonstrating growth and consistency over time | Progress page, parent evidence review |
| **Tamper-Evident Evidence Log** | Auditable provenance timeline | Evidence disclosure, DPDP audit trails |
| **Categorical Matrix** | Grouping learners by misconception clusters | Teacher action queue |
| **Fisher Information Curve** | Test information across theta scale | Psychometric Item Studio ONLY |
| **Multi-Tier Radial Map** | Holistic cognitive/inquiry/metacognitive spectrum | Progressive disclosure behind explicit toggle |

---

## 3. False Precision Law
- **FORBIDDEN:** Percentage readiness or probability-of-success metrics (e.g. "74% career fit", "82% readiness").
- **REQUIRED:** Qualitative developmental tiers (*"Strong foundation"*, *"Developing foundation"*, *"4 of 6 foundational competencies demonstrated"*).
