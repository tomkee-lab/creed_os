# WAY 2.1 Responsive Grid & Layout

## 1. Column System
- **Desktop ($\ge 1024px$):** 12 columns, maximum container width $\approx 1440px$ (`max-w-6xl` or `max-w-7xl`).
- **Tablet ($768px - 1023px$):** 8 columns.
- **Mobile ($< 768px$):** 4 columns.

---

## 2. Asymmetric Editorial Balance
Standard dashboard templates force equal 33% / 33% / 33% columns everywhere, creating visual monotony.
WAY 2.1 employs intentional asymmetric balance based on content priority:
- **60 / 40 (or 7 / 5 cols):** Hero illustration alongside the primary `DecisionSurface`.
- **70 / 30:** Primary working surface alongside a compact action queue.
- **50 / 50:** Balanced dual-field comparisons (e.g. Robotics vs Bio-Discovery).
- **Full Width with Disclosures:** Deep case tables, complex diagnostics, and timeline streams.

---

## 3. Negative Space & Content Ratios
- **WAY Experience (Student, Parent):** 60% Content / 40% Whitespace. Breathing room encourages calm reflective engagement.
- **WAY Console (Teacher, Counselor, Admin, Studio):** 75% Content / 25% Whitespace. Optimized for operational scannability and high data density.
- **Marketing & Landing:** 45% Content / 55% Whitespace. Evocative storytelling with premium visual pauses.
