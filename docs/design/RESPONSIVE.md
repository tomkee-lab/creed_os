# WAY 2.1 Responsive Behavior

## 1. Role-First Viewport Prioritization
- **Student Experience:** Mobile-first and tablet-optimized. Fast touch targets ($\ge 44px$) and clean vertical stacking.
- **Parent Portal:** Mobile-first. Reassuring status visible without horizontal scrolling.
- **Teacher Workspace:** Tablet and desktop-first. Designed for classroom triage while circulating with an iPad or laptop.
- **Counselor & Admin Console:** Desktop-first ($1280px+$ recommended). High-density data tables and persistent filter bars.
- **Item Studio:** Desktop-only workspace with side-by-side authoring and parameter calibration curves.

---

## 2. Adaptive Layout Transformations
- **Navigation:** Header collapses to mobile navigation slide-over on viewports $< 768px$.
- **Decision Surfaces:** Asymmetric 60/40 desktop balance shifts gracefully to single-column vertical stack on mobile.
- **Data Tables:** Horizontal scrolling with sticky identifier columns or conversion to card rows on small screens.
