# WAY 2.1 Information Density Modes

## 1. Bifurcated Paradigms: One Brand, Two Densities
CREED OS maintains two distinct density modes sharing identical color tokens, typography stacks, and interaction physics. The difference is solely in information density, not brand identity.

---

## 2. WAY Experience (Comfortable Density)
- **Target Roles:** Student, Parent.
- **Characteristics:**
  - Row height: $48px - 56px$.
  - Generous internal padding (`p-6` to `p-8`).
  - Narrative typography hierarchy.
  - Large expressive artwork establishing context.
  - Deep analytics deferred behind progressive disclosures (`EvidenceDisclosure`).
  - Cognitive target: Understand status in $\le 5 - 10$ seconds.

---

## 3. WAY Console (Compact / High Density)
- **Target Roles:** Teacher, Counselor, Admin, Item Studio.
- **Characteristics:**
  - Row height: $36px - 40px$ (Carbon standard).
  - Compact table padding (`py-2.5` to `py-3`, `px-3.5`).
  - Persistent filter bars and search inputs.
  - Keyboard navigation shortcuts.
  - Side drawers for deep case inspection without page unloading.
  - Cognitive target: Identify intervention priority in $\le 10$ seconds.
