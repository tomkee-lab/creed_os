# WAY 2.1 Typography

## 1. Font Families
- **Primary Body & UI:** `Inter Variable`, modern neutral sans-serif with exceptional scannability and multi-device clarity.
- **Headings & Landmarks:** `DM Sans Variable`, warm modern geometric sans providing human clarity without excessive quirkiness.
- **Technical & Psychometrics:** `JetBrains Mono`, strictly reserved for raw identifiers, 3PL parameters, code tokens, and audit timestamps.
- **Monospace Budget Rule:** Monospace typography must constitute **$\le 5\%$** of any visible viewport in experience routes.

---

## 2. Scale & Hierarchy
| Level | Desktop Size | Line Height | Weight | Usage |
| :--- | :--- | :--- | :--- | :--- |
| **Display** | 48–56px | 1.1 | Bold / ExtraBold | Marketing & Landing hero statements only |
| **H1** | 32–40px | 1.2 | Bold | Single primary landmark header per page |
| **H2** | 24–28px | 1.25 | Bold | Major section headings (`WaySection`) |
| **H3** | 18–20px | 1.3 | SemiBold / Bold | Content objects, card/panel headers |
| **Body** | 15–17px | 1.6 | Regular / Medium | Primary reading copy, questions, narrative |
| **Supporting** | 13–14px | 1.5 | Regular | Secondary explanations, sublabels |
| **Meta / Micro** | 11–12px | 1.4 | Medium / SemiBold | Status badges, timestamps, audit references |

---

## 3. Case Discipline
- **Default:** Sentence case for all titles, buttons, section labels, and menu items.
- **FORBIDDEN:** Gratuitous uppercase labels above every heading (e.g. `ALL-CAPS LABEL + TITLE + DESCRIPTION + STATUS` pattern is strictly banned).
- **Exceptions:** Micro-badges (e.g. `DEV ONLY`, `CAT`, `DPDP`) may use uppercase if acronymous.
