# Greptile Code Review Integration Rules

1. **Strictly Preserve Invariants**: When fixing issues flagged by Greptile, NEVER introduce `npm` or `yarn` commands, never violate DPDP child consent rules, and never break WAY Design System tokens or Svelte 5 runes.
2. **Review Verification**: Before merging pull requests, ensure Greptile confidence score is 5/5 or all actionable issues have been addressed.
3. **Training & Feedback**: When Greptile comments are accurate, acknowledge with 👍. When intentional architectural decisions are flagged, reply with context so Greptile's graph learner adapts.
